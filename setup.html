設定小幫手

用相容的 Windows PC 開啟裸視 3D。

  1. 接上螢幕和 USB

    用 HDMI 或 DisplayPort 接螢幕，再接 USB 上行線，讓眼動追蹤運作。

  2. 從 Odyssey 3D Hub 開遊戲

    安裝 Hub 後重新開機。將 G90XF 設為主顯示器，解析度設為 3840 × 2160，關閉 Windows HDR。在 Hub 核對遊戲版本並啟動。

  3. 坐在螢幕正前方

    一次一人，距離約 55–95 公分。讓鏡頭看得到雙眼。

全螢幕影片，直接看裸視 3D

讓 Odyssey 3D Hub 在背景執行，關閉 Windows HDR。將相容影片切成全螢幕，在右下角選影片格式。

一般 2D 影片
選「2D」，由 AI 即時加入景深。需相容 NVIDIA RTX 顯示卡。
左右並排 3D 影片
選「並排（SBS）」，以裸視 3D 顯示影片原有的左右眼畫面。

調整立體感　部分 Hub 版本在啟用轉換後會顯示 3D 設定。看到景深選項時，可從低強度往上調。選項依 Hub 版本與影片模式而異。
