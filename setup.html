設定小幫手

用相容的 Windows PC 開啟裸視 3D。

  1. 接上螢幕和 USB

    用 HDMI 或 DisplayPort 接螢幕，再接 USB 上行線，讓眼動追蹤運作。

  2. 從 Odyssey 3D Hub 開遊戲

    安裝 Hub 後重新開機。將 G90XF 設為主顯示器，解析度設為 3840 × 2160，關閉 Windows HDR。在 Hub 核對遊戲版本並啟動。

  3. 坐在螢幕正前方

    一次一人，距離約 55–95 公分。讓鏡頭看得到雙眼。
