Odyssey 3D Hub

如何啟用裸視 3D

準備相容的 Windows 電腦、Odyssey 3D G90XF 與支援遊戲。

01

接上螢幕

用 HDMI 或 DisplayPort 接上電腦，再接上 USB 上行線，讓眼動追蹤可以運作。

02

安裝 Hub 並啟動遊戲

安裝 Odyssey 3D Hub 後重新開機。將螢幕設為橫向主顯示器，Windows 解析度設為 3840 × 2160，並關閉 Windows HDR。在 Hub 核對相容的遊戲與商店版本後，從 Hub 啟動。

03

坐在螢幕正前方

一次一人，距離約 55–95 公分。讓攝影機看見完整臉部，避免強光直照鏡頭。
