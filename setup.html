電腦配備建議

作業系統
Windows 11，或 Windows 10 22H2（64 位元）
玩 3D 遊戲
使用 Windows 桌機，CPU、顯示卡與記憶體依各款遊戲需求搭配。
一般影片轉 3D
NVIDIA 桌機顯示卡：RTX 3080（30 系列）或 RTX 4070（40 系列）起。
Intel Core i7 或 AMD Ryzen 7 1700X 以上；建議 DDR5-5600 32 GB × 2。
安裝 Hub
至少 2 GB 記憶體、4 GB 可用儲存空間。
